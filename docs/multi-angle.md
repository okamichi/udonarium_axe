# 2D 多方向閲覧と外周ティッカー

画面を水平に置き、卓の四方から同じ盤面を見るための表示機能です。コマ名を円周に沿って回し、コマ画像もゆっくり回転させます。チャットの投稿を画面の外周へ流すティッカーと、ウィンドウを 90°ずつ回す操作も利用できます。

多方向閲覧とティッカーは、どちらも 2D モードでだけ動作します。既存の部屋の表示を変えないよう、初期状態では無効です。

## 多方向閲覧を有効にする

1. 画面左上のメニューから「テーブル設定」を開きます。
2. 「表示モード」で「2D モード（俯瞰固定）」を有効にします。
3. その下に現れる「コマ名を円周に沿って周回」を有効にします。
4. 必要に応じて回転方法と時間を調整します。

設定はテーブルごとに保存・同期されるため、同じ部屋の参加者には同じ値が反映されます。

### 回転設定

| 設定               | 内容                                  | 範囲      | 初期値 |
| ------------------ | ------------------------------------- | --------- | ------ |
| 回転方法           | 連続回転、または 90°回転して静止      | 2 種類    | 連続   |
| 回転時間（一周）   | 円周上のラベルが一周するまでの時間    | 1～120 秒 | 12 秒  |
| 90°後の静止時間    | 間欠回転で、90°回ったあとに止まる時間 | 0～30 秒  | 2 秒   |
| コマ本体の一周時間 | コマ画像と台座が一周するまでの時間    | 5～300 秒 | 60 秒  |

「90°後の静止時間」は、回転方法が「90°回転して静止」のときだけ表示されます。

## コマの表示

- ラベルは `キャラクター名/バフ名の先頭5文字` を基本にします。バフがない場合や、コマ側でバフを隠している場合はキャラクター名だけを表示します。
- 文字列は円周に沿って一文字ずつ曲がります。短い文字列は四方に4個置き、長さに応じて3個、2個、1個へ減らします。
- 複数のラベルは `◆` と余白で区切り、隣のラベルと連結して見えないようにします。
- ラベルは時計回りに周回します。コマ画像と台座は、ラベルとは別に設定した速度で平面上を回転します。
- すべてのコマが同時に同じ方向を向かないよう、コマごとに開始角をずらします。同じコマの開始角は参加者間で一致します。
- HP・MPなどのバー、増減値、バフ・状態アイコン、ターゲット表示は回転させません。
- コマへマウスを乗せたときの詳細表示は、コマ中心から見たポインター位置を90°ごとの領域に分け、その側から読める向きへ変わります。

ポスター表示は多方向閲覧の対象外です。2D モードまたは多方向閲覧を無効にすると、従来のコマ名表示へ戻ります。

## 外周ティッカー

外周ティッカーは、チャットの固定タブ「ティッカー」へ投稿した内容を画面の四辺へ流します。多方向のコマ名表示を無効にしていても、2D モードであればティッカーだけを使用できます。

### 使い方

1. チャットウィンドウを開き、「ティッカー」タブを選びます。
2. タブ内の「外周ティッカーを表示」を有効にします。
3. 速度スライダーを調整します。設定範囲は 20～240 px/秒、初期値は 55 px/秒です。
4. 通常のチャットと同じように投稿します。

「ティッカー」タブは削除や改名ができません。投稿履歴と表示設定は部屋の参加者へ同期されます。

### 流れる向き

文字の上側を画面中央へ向けたまま、画面を時計回りに一周します。

| 辺   | 移動方向 | 文字の向き |
| ---- | -------- | ---------- |
| 下辺 | 右から左 | 通常       |
| 左辺 | 下から上 | 左向き     |
| 上辺 | 左から右 | 上下反転   |
| 右辺 | 上から下 | 右向き     |

新しい投稿は順番に一周します。待機中に新しい投稿が届けばその投稿へ切り替わり、投稿待ちの間は最後の内容を繰り返します。

短い投稿では、同じ内容を `◆` 区切りで最大8個まで複製し、外周へ等間隔に配置します。文章が長い場合は、コピー同士の間隔を保てるよう7個から1個まで自動的に減らします。画面に収まらないほど長い文章は末尾を省略します。

表示対象は全員に公開された通常発言です。秘話、シークレット発言、システムメッセージはティッカーへ流しません。

## ウィンドウを90°回転する

キャラクター詳細、チャット、チャットパレット、インベントリなど、共通のウィンドウ枠を使う画面には右上に回転ボタンがあります。押すたびに時計回りで `0° → 90° → 180° → 270° → 0°` と切り替わります。

回転後も移動、リサイズ、縮小、全画面表示、閉じる操作を使えます。90°または270°で全画面表示にすると縦横を入れ替え、画面からはみ出さない位置へ補正します。

回転角は開いているウィンドウごとの一時的な状態です。部屋には同期せず、ウィンドウを閉じて開き直すと0°へ戻ります。狭い画面向けのモバイル表示では回転ボタンを表示しません。

## ローカルで確認する

開発サーバーを起動し、SkyWayへ接続しないローカル確認モードで開きます。

```sh
npm start
```

<http://localhost:4200/?local=1>

テーブル設定で2Dモードを有効にし、コマ名の周回、外周ティッカー、ウィンドウ回転を順に確認してください。
