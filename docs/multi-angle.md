# 2D 多方向閲覧・回転メニュー・外周ティッカー

画面を水平に置き、卓の四方から同じ盤面を見るための表示機能です。2D モードでは、コマ名とコマ本体の回転、四方向から操作できるコマメニュー、チャットを画面外周へ流すティッカーを利用できます。任意の共通ウィンドウを 90°ずつ回す操作は、2D・3Dどちらの表示モードでも利用できます。

2D モード、平行投影、回転メニュー、コマ名の周回、リソース・バフ回転表示、外周ティッカーは、既存の部屋の表示を変えないよう初期状態では無効です。テーブル設定はテーブルごとに保存・同期され、同じ部屋の参加者へ反映されます。ウィンドウの回転角だけは各端末の一時的な状態です。

## 2D モードを有効にする

1. 画面左上のメニューから「テーブル設定」を開きます。
2. 「表示モード」で「2D モード（俯瞰固定）」を有効にします。
3. 必要に応じて「平行投影」「地形の回転を許可（通常は2Dモードでは固定）」「回転メニュー表示」「コマ名を円周に沿って周回」を有効にします。リソースとバフも回す場合は、コマ名の周回設定内にある「リソースバフ回転表示（最大4つまで）」も有効にします。

2D モードへ切り替えたときは、それまで傾いていたベースマップを自動補正し、真上から見下ろす状態に戻します。以後は見下ろす角度を固定したまま、平行移動、拡大縮小、盤面の水平回転を行えます。

「地形の回転を許可（通常は2Dモードでは固定）」はデフォルトOFFです。ONにすると、2Dモードでも地形の端や四隅に表示される回転ハンドルをドラッグして向きを変えられます。

### 平行投影

「平行投影」はデフォルト OFF です。

- OFF：真上視点を固定しますが、通常の遠近感は残ります。
- ON：遠近感をなくし、画面上のどの位置でも同じ向き・同じ縮尺で描画します。マップの端へ移動したコマの側面が、視点位置の違いによって見えやすくなる現象も抑えられます。

## 2D モードのコンテキストメニュー

2D モードでコマ、地形、卓上に配置した環境エフェクト、またはテーブルの何もない場所を右クリックすると、四方向から操作できるメニューを表示します。地形では「地形・扉」「見た目・照明」「移動・作成」「オブジェクト操作」、環境エフェクトでは「見た目」と「オブジェクト操作」に項目を分類します。空白部分では「最初のテーブル」など、現在のテーブル名がタイトルになります。「回転メニュー表示」の ON/OFF で表示方法が変わります。

コマが密集している場合は、コマから右ドラッグして任意の場所で離すと、離した場所を見かけ上の中心として同じメニューを表示できます。ドラッグ中は見かけ上の中心を小さな輪と点で示します。実際のコマ中心からメニュー中心までは点線で結ばれ、画面端ではメニュー全体が収まる位置へさらに補正されます。移動せずに右クリックした場合は従来どおりコマ中心へ表示します。テーブルの空白部分から始める右ドラッグは、従来どおり盤面の水平回転です。

### 「回転メニュー表示」が OFF の場合

1. 右クリックした位置の上下左右に4個のハンバーガーアイコンを表示します。コマの場合はコマの外側へ配置します。
2. 操作する人の側にあるアイコンを選びます。
3. 選んだ側から読める向きで、通常のプルダウンメニューを開きます。

プルダウンメニューの表示起点は右クリック位置やコマ中心ではなく、選んだハンバーガーアイコンの位置です。コマでは半径ぶん以上離れるため、メニュー上部とコマが重なりにくくなっています。

### 「回転メニュー表示」が ON の場合

メニューの分類や項目が、右クリック位置（コマの場合はコマ）の周囲を時計回りに回転します。回転速度は「回転速度」で 1～24°/秒に設定でき、初期値は 5°/秒です。

メニューの中心から円周へ伸びる水色の点線は、ウィンドウの向きが切り替わる境界です。X字の境界で区切られた各90°の範囲にある矢印が、その範囲の項目をクリックしたときに補正されるウィンドウの向きを示します。境界と矢印は画面に固定され、メニュー項目だけがその上を回転します。点線はコマの背後を通るように中央部分を隠すため、コマ画像の視認性を損ないません。

- 項目を選ぶと、下位項目がある場合は同じ位置を起点にサブメニューへ切り替わります。
- 1ページには通常項目を最大7個表示し、残りの1枠に「戻る」を表示します。
- 項目が8個以上ある場合、途中のページでは「戻る」の代わりに `1 / 2` のようなページ表示を置きます。クリックすると次のページへ進み、最終ページではページ表示に代わって「戻る」が現れます。
- 周回項目の「戻る」は、サブメニューでは一つ前へ戻り、最上位ではメニューを閉じます。前のページを見直す場合は、「戻る」からそのメニューへ入り直します。
- 中央にはメニューを表示しません。回転メニューを開いたまま右クリックすると、現在表示されている1項目ぶんだけ、短い高速回転で滑らかに時計回りへ先送りします。表示が3項目なら120°、4項目なら90°、6項目なら60°進み、割り切れない項目数では小数角を保ったまま一周の誤差を補正します。高速回転後は内部角度を0〜360°未満へ戻すため、操作を繰り返しても角度値は増え続けません。

2×2、3×3などの大きいコマでは、ハンバーガーアイコンと回転メニューの半径もコマサイズに応じて広がります。コマ名の周回表示が ON でも OFF でも距離は変わらず、コマ名の外側にメニューが配置されます。1×1のコマは従来の距離を使用します。

「回転メニュー表示」と「回転速度」のラベルへマウスを乗せると、使い方の説明を表示します。

### メニューの向きと、開くウィンドウの向き

ハンバーガーアイコンから開いた通常メニューと、そこから開く共通ウィンドウやモーダルウィンドウは、コマ上・テーブル空白部分のどちらでも、選んだ四方向の向きを引き継ぎます。

回転メニューの項目から共通ウィンドウやモーダルウィンドウを開いた場合は、クリックした項目がその瞬間に向いていた方向を基準にします。表示角度は最も近い 0°、90°、180°、270°へ補正されます。手元から読みやすい向きにしたい場合は、右クリックでメニューを1項目ずつ送り、目的の項目が手元側へ来たときにクリックしてください。

## コマ名とコマ本体の回転

「コマ名を円周に沿って周回」を有効にすると、コマ名を円周に沿って表示し、コマ画像と台座も平面上で回転します。

### 回転方法

| 回転方法                | コマ名                               | コマ本体                               |
| ----------------------- | ------------------------------------ | -------------------------------------- |
| 時計回りに連続回転      | 「回転時間（一周）」の速度で連続回転 | 「コマ本体の一周時間」の速度で連続回転 |
| 90°回転して静止         | 90°回転して静止する動作を繰り返す    | 90°回転して静止する動作を繰り返す      |
| コマだけ90°回転して停止 | 「回転時間（一周）」の速度で連続回転 | 90°回転して静止する動作を繰り返す      |

「90°回転して静止」は、コマ名だけでなくコマ画像と台座も同じように90°ごとに止まります。「コマだけ90°回転して停止」では、コマ名は連続回転し、コマ画像と台座だけが90°ごとに止まります。

### 回転設定

| 設定               | 内容                                         | 範囲      | 初期値 |
| ------------------ | -------------------------------------------- | --------- | ------ |
| 回転時間（一周）   | コマ名が一周するための回転時間               | 1～120 秒 | 12 秒  |
| コマ本体の一周時間 | コマ画像と台座が一周するための回転時間       | 5～300 秒 | 60 秒  |
| 90°後の静止時間    | 90°回転したあと、次の90°回転まで静止する時間 | 0～30 秒  | 4 秒   |

「90°後の静止時間」は「90°回転して静止」と「コマだけ90°回転して停止」で表示されます。0秒にすると停止時間がなくなり、連続して回転します。

回転方法で「時計回りに連続回転」を選ぶと、「コマ本体の一周時間」は60秒へ戻ります。「90°回転して静止」または「コマだけ90°回転して停止」を選ぶと、5秒へ戻ります。

### コマ上の表示

- 「リソースバフ回転表示（最大4つまで）」が OFF のとき、ラベルは `キャラクター名/バフ名の先頭5文字` を基本にします。バフがない場合や、コマ側でバフを隠している場合はキャラクター名だけを表示します。
- 文字列は円周に沿って一文字ずつ曲がります。短い文字列は四方に4個置き、長さに応じて3個、2個、1個へ減らします。
- 複数のラベルは `◆` と余白で区切ります。円周の継ぎ目に来た文字列も途切れないよう補完して描画します。
- すべてのコマが同時に同じ方向を向かないよう、コマごとに開始角をずらします。同じコマの開始角は参加者間で一致します。
- 「リソースバフ回転表示（最大4つまで）」を有効にすると、通常の横長リソースバーと固定バフ表示を外周表示へ切り替えます。名前とは回転レイヤーを分け、名前の1.25倍の時間をかけて少しゆっくり周回するため、頭文字やアイコンとの重なりが同じ位置に固定されません。
- リソースは台座の外周を最大4件で分割し、1件なら360°、2件なら各180°、3件なら各120°、4件なら各90°を割り当てます。2件以上では各区画の境界を黒い放射線で区切ります。各区画は現在値の割合だけ色が付き、識別用の頭文字だけを表示して数値は表示しません。5件目以降は外周へ表示しません。
- バフはアイコンだけを名前とリソースの外側へ均等配置します。数が多い場合は、アイコン同士が重なりにくいよう外周半径を広げます。「バフを隠す」が有効なコマには表示しません。
- 増減値とターゲット表示は回転させません。
- HP・MPなどのバーは、キャラクターシートを編集状態にし、対象の数値・リソース欄にある設定ボタンから「コマにバーを表示」を切り替えられます。
- コマへマウスを乗せたときの詳細表示は、コマ中心から見たポインター位置を90°ごとの領域に分け、その側から読める向きへ変わります。
- スクエアグリッドの台座は角の丸みが一定のため、1×1では円形、2×2以上では角丸の四角形に見えます。ヘクスグリッドではヘクス形状になります。

ポスター表示は多方向閲覧の対象外です。2D モードまたはコマ名の周回を無効にすると、従来のコマ名表示へ戻ります。

## 外周ティッカー

外周ティッカーは、チャットの固定タブ「ティッカー」へ投稿した内容を画面の四辺へ流すティッカーチャットです。「コマ名を円周に沿って周回」が OFF でも、2D モードであればティッカーだけを使用できます。

### 使い方

1. チャットウィンドウを開き、「ティッカー」タブを選びます。
2. タブ内の「外周ティッカーを表示」を有効にします。
3. 速度スライダーを調整します。設定範囲は 20～240 px/秒、初期値は 55 px/秒です。
4. 通常のチャットと同じように投稿します。

「ティッカー」タブは削除や改名ができません。外周表示は2Dモードでのみ表示され、投稿がまだない場合は何も表示しません。投稿履歴、表示のON/OFF、速度は部屋の参加者へ同期されます。

ほかのタブにある公開メッセージは、上部の操作列にある「ティッカー」アイコンを押すと、全参加者の外周ティッカーへ一時的に表示できます。別のメッセージで同じ操作をするとそちらへ切り替わり、「ティッカー」タブへ新規投稿があると新しい投稿が優先されます。この操作では表示のON/OFFや速度を変更せず、「ティッカー」タブで設定した状態をそのまま使用します。

### 流れる向き

文字の上側を画面中央へ向けたまま、画面を時計回りに一周します。

| 辺   | 移動方向 | 文字の向き |
| ---- | -------- | ---------- |
| 下辺 | 右から左 | 通常       |
| 左辺 | 下から上 | 左向き     |
| 上辺 | 左から右 | 上下反転   |
| 右辺 | 上から下 | 右向き     |

新しい投稿が届くと、外周の表示は次の描画からすぐにその投稿へ切り替わります。新しい投稿を待つ間は最後の内容を繰り返します。

短い投稿では、発言者名と本文に `◆` を添えた同じ内容を最大8個まで複製し、外周へ等間隔に配置します。文章が長い場合は、コピー同士が重ならない個数まで自動的に減らします。外周一周の90%に収まらない文章は末尾を `…` で省略します。

表示対象は全員に公開された通常発言です。秘話、シークレット発言、システムメッセージ、空の発言には「ティッカー」アイコンを表示せず、外周にも流しません。

## ウィンドウを90°回転する

キャラクター詳細、チャット、チャットパレット、インベントリなど、共通のウィンドウ枠で開く任意のウィンドウには、タイトルバー右上に「時計回りに90度回転」ボタンがあります。押すたびに `0° → 90° → 180° → 270° → 0°` と切り替わります。

回転後も移動、リサイズ、縮小、全画面表示、閉じる操作を使えます。90°または270°で全画面表示にすると縦横を入れ替え、画面からはみ出さない位置へ補正します。

コマの方向メニューから開いたウィンドウは、そのメニュー項目の向きを初期角度として使用します。開いたあとは、ウィンドウ右上の回転ボタンでさらに90°ずつ調整できます。メニュー以外から通常どおり開いたウィンドウは0°で始まります。

回転角は開いているウィンドウごとの一時的な状態で、部屋には同期しません。閉じるとその角度は破棄されます。狭い画面向けのモバイル表示では回転ボタンを表示せず、通常の向きで表示します。

## ローカルで確認する

開発サーバーを起動し、SkyWayへ接続しないローカル確認モードで開きます。

```sh
npm start
```

<http://localhost:4200/?local=1>

テーブル設定で2Dモードを有効にし、平行投影、2種類のコマメニュー、3種類のコマ回転、外周ティッカー、ウィンドウ回転を順に確認してください。
